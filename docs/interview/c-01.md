Preparing for a technical interview is a systematic process. For the ADMIRAL position, we will focus on **NestJS/Node.js, Angular, and system design** as the core pillars.
---

## 📚 **Phase 1: Core Technology Deep Dive**

### **A. Node.js & JavaScript/TypeScript Fundamentals**
These are the non-negotiable basics. You must be fluent.

**Key Concepts to Master:**
1.  **Event Loop & Async Programming:**
    *   Explain the event loop in detail (call stack, microtasks, macrotasks).
    *   Differences between `setTimeout`, `setImmediate`, `process.nextTick`.
    *   **Practice Question:** "What is the output order of this code involving promises and timeouts?"
2.  **Promises & Async/Await:**
    *   Convert callback-based code to promises/async-await.
    *   Error handling with `try/catch` and `.catch()`.
    *   `Promise.all`, `Promise.allSettled`, `Promise.race`.
3.  **Streams & Performance:**
    *   Why use streams? (Memory efficiency for large data).
    *   Explain `pipe()`. Know the 4 types: Readable, Writable, Duplex, Transform.
4.  **JavaScript/TypeScript Specifics:**
    *   `this` context, `bind`, `call`, `apply`.
    *   Closures and their practical uses (e.g., data privacy, currying).
    *   ES6+ features: destructuring, spread/rest operators, modules (`import/export`).
    *   TypeScript: Interfaces vs Types, generics, decorators (critical for NestJS).

### **B. NestJS Framework (The Star of the Show)**
This is likely their main focus. You need to know it conceptually and practically.

**Architecture & Core Concepts:**
1.  **Module:** The organizing unit. Know how to create and import them. Understand `@Global()`.
2.  **Provider/Service:** The business logic layer. Explain Dependency Injection (DI) and how Nest's IoC (Inversion of Control) container works.
    *   Be ready to draw or explain the DI flow.
3.  **Controller:** The API layer. Handling routes, params (`@Param`), queries (`@Query`), body (`@Body`).
4.  **Pipes, Guards, Interceptors, Middleware:**
    *   **Pipes:** For validation and transformation (e.g., `ParseIntPipe`, custom validation with `class-validator`).
    *   **Guards:** For authentication and authorization (e.g., `JwtGuard`, `RolesGuard`).
    *   **Interceptors:** For manipulating request/response flow (e.g., logging, transforming response shape, error mapping).
    *   Know the **order of execution**: Middleware -> Guards -> Interceptors (before) -> Pipes -> Controller -> Interceptors (after) -> Filters.
5.  **Exception Filters:** How to create custom global exception filters for unified error responses.
6.  **Practical Patterns:**
    *   How do you structure a large project? (Feature modules, shared modules, core modules).
    *   How do you handle configuration? (Using `ConfigModule`, `.env` files).
    *   How do you connect to a database? (Using `TypeORM` or `Prisma` modules).

**Expected Question:** *"Walk me through what happens when a POST request hits your NestJS endpoint, from the moment it enters the application to the moment a response is sent."*

### **C. Angular Framework**
Since it's a full-stack role, be prepared for Angular fundamentals.

**Key Concepts:**
1.  **Components & Data Binding:** Property binding `[ ]`, event binding `( )`, two-way binding `[( )]`.
2.  **Services & Dependency Injection:** How Angular's DI works (hierarchical injectors).
3.  **RxJS & Observables:** This is crucial.
    *   Explain an `Observable` vs a `Promise`.
    *   Know basic operators: `map`, `filter`, `switchMap`, `catchError`, `tap`.
    *   How to manage subscriptions (and avoid memory leaks) using `async` pipe or manual cleanup.
4.  **State Management:** Be prepared to discuss basic component state vs. services. Knowing NgRx or a similar library is a bonus.
5.  **Routing:** Lazy loading modules, route guards, route parameters.

### **D. Databases**
Be ready to compare and choose.

**SQL (SQL Server / PostgreSQL):**
*   Write basic joins (INNER, LEFT).
*   Explain indexing and when it helps/hurts.
*   What is a transaction (ACID properties)?

**NoSQL (MongoDB):**
*   Document structure and embedding vs. referencing.
*   When would you choose MongoDB over a SQL DB? (Flexible schema, unstructured/rapidly changing data, horizontal scaling needs).

**Expected Question:** *"For a feature like user profiles with addresses (1-to-many) and orders (many-to-many), how would you model this in SQL and in MongoDB? What are the trade-offs?"*

## 💻 **Phase 2: Practical Coding & Problem-Solving**

### **A. Live Coding Challenge**
You will almost certainly have a live coding session (using a tool like CodePen, HackerRank, or a shared IDE).

**Types of Problems:**
1.  **Algorithmic (Medium Difficulty):** Focus on array/string manipulation, object transformations. Not likely heavy LeetCode, but be prepared.
    *   Example: "Write a function to validate/format data from an API."
2.  **Practical Node.js/NestJS:**
    *   "Create a simple REST endpoint for a todo list (GET, POST)."
    *   "Add validation so the `title` field is required and a string."
    *   "Add a guard that checks for a simple API key in the header."
3.  **Debugging & Refactoring:** They might give you a piece of buggy or poorly structured code and ask you to fix/improve it.

**Practice Resources:**
*   Build a simple **NestJS CRUD API** from scratch (e.g., for a blog or product catalog) with a module, service, controller, validation, and error handling.
*   Practice on **Edabit** or **Codewars** (JavaScript, 5-6 kyu level).

### **B. System Design (For Mid/Senior Level)**
You might get a high-level design question to assess your architectural thinking.

**Possible Prompt:** *"Design a URL shortening service like bit.ly."* or *"How would you structure the backend for a real-time dashboard showing filtration machine metrics (hinting at LENSER's domain)?"*

**Use a Structured Approach (CLEAR Method):**
1.  **Clarify Requirements:** Ask questions! Scope the problem. (e.g., "What's the expected QPS? What are the core features?")
2.  **List Components:** Sketch out high-level blocks: Client, API Gateway, Application Servers (NestJS), Databases, Cache, File Storage.
3.  **Estimate Scale:** Do quick back-of-the-envelope math (traffic, storage). This shows practical sense.
4.  **Architect Deep Dive:** Zoom into 1-2 areas. For a URL shortener, dive into the hash generation algorithm or database schema.
5.  **Review Trade-offs:** Discuss choices (SQL vs NoSQL for this case, memory cache vs. database).

## 🔧 **Phase 3: DevOps & Tooling ("Buzzwords")**

Be prepared to discuss concepts, even if you haven't implemented them end-to-end.

*   **Docker:** What is a Dockerfile? What is the difference between an image and a container? Know basic commands (`docker build`, `docker run`).
*   **Kubernetes (K8s):** Explain at a high level: it's an orchestration system for containers. Know key concepts: Pod, Deployment, Service, Ingress. *"It manages the deployment, scaling, and networking of our containerized applications."*
*   **AWS:** Know the core services: EC2 (servers), S3 (storage), RDS (managed SQL), maybe Lambda (serverless). Be ready to say, "I have experience with X, and I understand the concepts of Y and Z."
*   **CI/CD (GitLab):** Explain what Continuous Integration and Continuous Delivery mean. "We merge code often, run automated tests, and have automated deployment pipelines."
*   **Testing:** Be ready to write a simple unit test (Jest) for a function. Explain the pyramid: many unit tests, fewer integration tests, very few E2E tests.

## 🗣️ **Phase 4: Behavioral & Situational Questions**

Use the **STAR method** (Situation, Task, Action, Result) for every answer.

**Prepare Stories For:**
1.  **Technical Challenge:** "Tell me about a time you debugged a complex production issue."
2.  **Team Conflict:** "Describe a disagreement you had about a technical approach and how you resolved it."
3.  **Learning & Growth:** "How do you stay updated? Tell me about a new technology you learned recently."
4.  **Ownership & Proactivity:** "Give an example of a time you went beyond your assigned tasks to improve something."
5.  **Mindset:** "What does 'clean code' mean to you?" (Answer: Readable, testable, maintainable, follows agreed-upon conventions.)

## ✅ **Your 7-Day Preparation Plan**

*   **Day 1-2:** **NestJS Deep Dive.** Build a CRUD API with 2-3 entities, using all core concepts (Modules, Services, Controllers, Pipes, Guards, Interceptors). Deploy it locally.
*   **Day 3:** **Angular & RxJS.** Build a simple frontend for your API. Practice using Angular services and RxJS operators.
*   **Day 4:** **Databases & System Design.** Review SQL/NoSQL concepts. Practice one system design question (out loud or on paper).
*   **Day 5:** **Node.js Fundamentals & DevOps.** Revise Event Loop, Promises, Streams. Research Docker/K8s/AWS concepts until you can explain them simply.
*   **Day 6:** **Coding Practice & Behavioral Prep.** Do 3-5 coding challenges. Write down your 5 STAR stories.
*   **Day 7:** **Mock Interview & Final Review.** Do a full mock interview with a friend or record yourself. Review key concepts.

### **Final Pro-Tips for the Interview:**

1.  **Think Aloud:** During coding, verbalize your thought process. It's more important than immediate perfection.
2.  **Ask Clarifying Questions:** Before diving into a problem, ask questions. It shows analytical thinking.
3.  **Admit What You Don't Know:** Say, "I haven't worked with Kubernetes directly, but I understand it's used for orchestration and I'm eager to learn." Then pivot to what you *do* know.
4.  **Show Enthusiasm:** Mention why you like their specific stack (e.g., "I appreciate NestJS's opinionated structure for large projects").
